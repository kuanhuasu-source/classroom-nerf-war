# 課桌大戰 Classroom Nerf War

瀏覽器第一人稱 Nerf 槍大戰原型，Three.js 製作。

## 開發

```bash
npm install
npm run dev            # 本機開發伺服器，開 http://localhost:5173
npm run build          # 產出 dist/，給 GitHub Pages
npm run build:single   # 產出 dist-single/index.html 單檔版，給 Claude Artifact
python3 tools/artifact-body.py dist-single/index.html out.html   # 轉成 Artifact 用的頁面
```

## 連線合作（最多四人）

首頁右邊有遊戲網址的 QR code，手機掃了直接開遊戲。開房間後房號旁邊會多一個帶房號的 QR code，隊友掃了會自動填好房號加入（網址形式是 `?room=房號`）。

首頁按「開房間」會得到四個字母的房號，隊友（最多三個）按「輸入房號」加入，房主看到名單到齊後按「開始」。首頁「連線時」那一列可以填自己的名字（最多 6 個字）和挑 8 種造型之一，會記住；沒填就用預設的小明（房主）、小美、阿強、小芳。預設走 PeerJS 的公用信令伺服器，房主與每個隊友各一條點對點連線（星狀），隊友之間不直接連。隊友的子彈會立刻出現（預覽彈，房主確認後無縫接手），其他人的動作用時間緩衝內插（約 80 到 350 ms，依抖動自動調），快照走無序通道、事件走有序通道。每個瀏覽器有一個記在 localStorage 的身分 id，斷線後 30 秒內用同一個瀏覽器重連會拿回原本的角色、升級與彈藥；中途加入也可以（會直接進場）。

本機測試可以自己架一個：

```bash
npx peerjs --port 9000 --path / --host 127.0.0.1
# 然後兩個分頁都開 http://localhost:5173/?peer=local
```

純程式測試用的假連線：同時開 `?role=host` 與 `?role=guest` 兩個分頁，兩邊的 `window.__transport` 互相搬運訊息（見 `src/net/transport.js`）。

平衡用的機器人：`tools/balance-bot.js` + `tools/balance-test.cjs` 跑單人，`tools/coop-bot.js` + `tools/coop-balance-test.cjs` 開兩個分頁走假連線跑雙人（參數：bot 所在資料夾、難度、場數），都需要先 `npm run build` 並在 `dist/` 起一個靜態伺服器在 8766 埠。

連線模式的差別：同學人數每多一個人 +40%（兩人 1.4 倍、四人 2.2 倍）、同時開火每多一人 +1、老師弱點 +1 到 +2 格、補彈盒同時最多「人數」盒；起始升級小明大彈匣、小美磁鐵手套、阿強連發扳機、小芳大書包；清波後不暫停，畫面下方的卡片列給 10 秒選升級，沒選自動拿第一張；牆上貼紙的 buff 誰射中誰拿（慢動作除外，整間教室一起慢）；補彈盒裝 30 發、會出現在比較缺彈的人附近；隊友 30 秒內重連會拿回原本的升級、彈藥和血量。

推到 `main` 分支會由 `.github/workflows/deploy.yml` 自動建置並部署到 GitHub Pages。

## 玩法

首頁「玩法」可選：

- **下課大戰**（預設）：六波同學加一位老師，撿地上的泡棉彈補充，五張地圖隨機或指定。
- **守校門**：隔壁學校的惡霸軍團闖進操場，守住十波。惡霸從校門衝進來、翻圍牆跳下來、掀水溝蓋鑽出來（紅頭巾、深色衣服，比同學多 1 滴血）。彈藥無限（備用彈顯示 ∞）。第 3 波惡霸老大（衝刺丟球）、第 6 波惡霸軍師（紙飛機、打電話叫人）、第 9 波惡霸打手（丟石子、吹哨衝刺）晚兩秒半跟著小弟進場，第 10 波惡霸大王每兩秒多就丟一顆板擦，被打中弱點還會再丟。頭目倒了小弟會慌，這波的小弟清光才算過；十波全擋下來就守住了。難度照一般的四級套用（同學的準度、同時開火人數、回血）。固定在操場，連線模式由開房的人選。
- **搶廁所**：下課想上廁所，清潔隊卻在打掃。只有三滴血、倒數 90 秒。清潔隊員（白圍裙藍帽子）會潑水，被潑到不扣血但行動變慢 5 秒（畫面泛藍）；也會用通馬桶的吸盤連發，一次 3 到 5 支，每支扣 1 滴血。清潔隊少於四個就會從側門再進一個。目標是射破全部 8 個罐子：最裡面大型小便斗架上 5 罐、三組洗手台各 1 罐，左上角顯示還剩幾罐；全破就贏（剩的秒數換分數）。時間到或三滴血用完就輸。固定在廁所地圖：一側四間隔間、一側洗手台、中間拖把桶當矮掩體。
- **午餐大作戰**（兩人限定，開房間找剛好一位隊友）：推車手推餐車沿 L 形走廊去蒸飯室裝菜，再推回六年二班；車頂射手擋沿途從教室門探頭丟彈的同學和追車挖菜的「搶菜王」。推車手 W/S 推煞、A/D 轉彎、F 喇叭（前方 3 公尺的同學嚇退，冷卻 6 秒），不能射擊；射手車上一箱 60 發，蒸飯室補滿。餐車有慣性，裝了菜更重更滑。裝菜要停在蒸飯室的黃圈裡 10 秒，裝完換手。回程撞牆、撞倒拖地水桶、在水灘上高速轉彎、被泡棉彈打中湯桶、被搶菜王貼車都會灑湯；午休鐘 150 秒。回到班上湯剩 80% 三顆星、50% 兩顆星、有剩一顆星；湯灑光、時間到或兩人同時被打倒就輸。

## 故事模式：Jason 的畢業週

首頁「故事模式」。六年二班的 Jason 在畢業前最後一週，每天一章，過了才開下一章，每章一到三顆星（看剩血、命中率、時間、湯量），進度存在瀏覽器。章節開頭是一頁聯絡簿（日期、天氣、日記、今天的目標），遊戲中小美會用泡泡提示，章尾一句日記加星星。

| 章 | 玩法 | 內容 |
|---|---|---|
| 星期一 最後一週的第一堂下課 | 下課大戰（小考） | 六年二班三波，數學老師 |
| 星期二 憋不住的第二節 | 搶廁所（小考） | 100 秒射破 8 罐 |
| 星期三 自然教室的綠色藥水 | 下課大戰（段考） | 自然教室四波，自然老師 |
| 星期四 午餐大作戰 | 午餐大作戰（段考） | 單人版：去程 Jason 推、小美上車射；裝完菜換手 |
| 星期五上午 隔壁學校來踢館 | 守校門（模擬考） | 六波，第 3 波惡霸老大、第 6 波大王 |
| 星期五下午 活動中心的會考委員會 | 下課大戰（模擬考） | 活動中心三波，會考委員會三人組 |
| 隱藏：畢業典禮 校長親自出馬 | 下課大戰（會考） | 五章全三星才出現 |

破完翻開「畢業紀念冊」：每章的星星、貼紙數、Jason 的最後一篇日記。故事模式固定 Jason 的造型（反戴藍帽、橘 T 恤、紅書包），首頁的難度與地圖選項對故事不生效，單人才能玩。

## 貼紙簿（成就）

首頁「貼紙簿」，24 張貼紙，解鎖時右下角會跳出來：通用 6（第一次下課、百發百中、毫髮無傷、牛奶控、撿破爛達人、同學們的惡夢）、下課大戰 6（全科制霸、主任再見、校長再見、會考狀元、會考過關、板擦閃避王）、守校門 3（守門員、摘皇冠、速戰速決）、搶廁所 3（來得及、乾爽、神射手）、午餐 3（全班吃飽、平穩駕駛、叭叭王）、故事 3（畢業快樂、全勤優等、校長的對手）。累計類的會顯示進度。

## 徽章

每打完一場抽一枚徽章：贏一定抽，輸了一半機率抽一枚（稀有度降一級）。稀有度看這場的難度（普通／精良／稀有／傳說，小考大多普通、會考常出稀有以上），多人再加一點機率。結算卡上有一張蓋著的卡，點一下翻開，可以直接佩戴。首頁「徽章」看收藏、佩戴、丟掉、合成（三枚同類同級合成高一級）。一次戴一枚，破完故事模式開第二格；收藏上限 40，滿了會自動丟掉最舊最低的一枚。

效果一枚一種，數值在稀有度的範圍內隨機：愛心上限 +1 到 +2、大彈匣 +2 到 +9 發、快手射速 +6% 到 +22%、連發（稀有以上）每次多 1 到 2 顆不耗彈但散得開、慢慢回血每 20 到 40 秒回 1 心、自動補彈每 12 到 25 秒備用 +5、快腿速度 +5% 到 +12%。連發的多顆彈對同一個人一次只算一下（打得更容易中，不是三倍傷害）；搶廁所的愛心徽章最多 +1。連線時各戴各的，隊友的徽章在進房時告訴主機；多人加碼照人數算，徽章不另外加碼。故事模式也套用，星星門檻不變。

## 辨識度

敵人（同學、清潔隊、惡霸、搶菜的、老師）腳下有紅圈；隊友腳下藍圈、名牌是藍底白字；被打倒罰坐、離場、投降的人整個變淡半透明、沒有圈；睡著的惡霸是灰圈，醒來變紅。

## 多人加碼

單人難度固定；多人時每多一個人就加碼：小怪人數 +60%、同時開火的人 +1.5 個、生怪間隔縮短 25%、準度 +10%、老師與頭目的弱點 +1 格、老師出手快 12%；每多兩個人小怪多 1 滴血；搶廁所的清潔隊 +1。守校門、搶廁所也套用。

## 手機平板全螢幕

- **Android（Chrome）**：按「開始」時會自動進全螢幕並鎖橫向；畫面右上也有「⛶」鈕可以切換。要常玩的話，Chrome 選單 → 「加到主畫面」或「安裝應用程式」，之後從主畫面圖示開就是全螢幕。
- **iPhone／iPad（Safari）**：Safari 不給網頁全螢幕，請用「分享 → 加入主畫面」，從主畫面圖示開啟就沒有網址列。iPad 的 Safari 可以按「⛶」。

## 難度

首頁可選小考／段考／模擬考／會考四級，預設段考。會考是給能穩過模擬考的人：同學更多更準、四個同時開火、彈速更快、老師更兇。差別在同時開火的人數上限、同學探頭到開火的延遲、彈速、每波人數與清波回血。細節見 `DESIGN.md` 4.4a。

## 升級

六波之後才是老師。鐘響時每個人會偷吃一口巧克力：回 3 ♥、補 20 發。每位老師隔一陣子會丟板擦，被打中弱點也會立刻氣得丟一顆；板擦落地炸出粉筆灰，站在裡面畫面會糊掉幾秒，快閃開（或校長、教務主任；活動中心在困難或雙人時還可能遇到會考委員會三人組，鐘響時記得蹲下）。每清一波從三張卡片選一個升級（彈匣、換彈、射速、雙管、彈速、磁鐵、書包、回收、蛙鏡、便當），按 1、2、3 或點卡片。單人模式選卡時暫停；雙人模式不暫停、10 秒內要選。老師戰時課桌上會出現鉛筆盒補彈。

## 教室裡要注意的

- 後排趴著睡覺的惡霸：別射他，他會丟書包（範圍攻擊）。
- 走道上的躲避球：射它可以把它打飛去撞同學。
- 垃圾桶：射倒會冒臭煙，煙裡的同學看不到也射不了。
- 前門上的水桶：射下來門口變水坑，走進來的同學直接滑倒出局，每波可用一次。
- 每波最後進來的是班長（紅臂章、名牌）：血多、更準，在場時其他同學更兇；先打倒她，其他人會慌。
- 牆上出現的貼紙：射中拿 buff（分數雙倍、彈匣不減、加速、慢動作）。
- 老師戰有機率換成大 Boss：教務主任（廣播音波要蹲、紙飛機、點名叫人）或校長（追蹤泡泡、頒獎砸地）。`?teacher=dean` / `?teacher=principal` 可指定。
- 五張地圖隨機或指定：六年二班、自然教室、音樂教室、活動中心、操場（首頁可選，`?map=yard` 可指定）。操場是戶外：溜滑梯高台可以上去、鞦韆會晃、生態池中間有木棧橋可以走過去、沙坑、升旗台、跑道。活動中心有舞台和二樓看台，同學會從二樓的門進來往下打，兩側的樓梯可以上去追。
- 老師戰是四位老師隨機一位：數學（丟粉筆）、體育（丟球、吹哨衝刺）、音樂（扇形音符）、自然（試管藥水攤、腳下實驗）。網址加 `?teacher=pe` 可指定。
